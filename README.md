# قیمت‌یار | Gheymat Yar

اپلیکیشن اندروید فارسی برای پایش بازار ارز، طلا، سکه و رمزارز.

## امکانات نسخه اولیه
- رابط کاربری فارسی و راست‌چین با Jetpack Compose
- صفحه خانه و دیده‌بان قابل انتخاب دارایی‌ها
- بازارها با دسته‌بندی طلا، ارز و رمزارز
- صفحه مبدل دارایی (فعلاً بدون نرخ زنده)
- تنظیمات واحد نمایش و حالت تاریک
- GitHub Actions برای ساخت APK تستی و خروجی Release امضاشده

**هشدار:** قیمت‌ها و ارقام فعلی نمونه و نمایشی هستند و نباید برای تصمیم مالی استفاده شوند. اتصال API معتبر، اعلان قیمت، ذخیره‌سازی پایدار، تست و سیاست حریم خصوصی پیش از انتشار عمومی لازم است.

## تنظیم امضای Release
در GitHub بروید به Settings → Secrets and variables → Actions و این چهار Secret را بسازید:

- `ANDROID_KEYSTORE_BASE64`: محتوای keystore به صورت Base64
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

فایل keystore را هرگز در Git commit نکنید. از کلید ثابت برای تمام به‌روزرسانی‌های برنامه استفاده کنید و یک نسخه پشتیبان امن آفلاین نگه دارید.

با ثبت Secrets، اجرای workflow از طریق `workflow_dispatch` یا Push به شاخه main خروجی‌های APK و AAB امضاشده را تولید می‌کند. بدون Secrets، APK تستی همچنان ساخته می‌شود.
